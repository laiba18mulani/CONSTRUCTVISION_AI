# ConstructVision AI Documentation Workspace

This folder is the publication workspace for the ConstructVision AI internship project.

## Deliverables

- `source/research_paper.md` - Q1-style research paper draft.
- `source/project_report.md` - industry-grade project report.
- `source/project_report.html` - styled, print-ready HTML report.
- `artifacts/` - generated Word and PDF files.
- `qa/` - render outputs used for visual verification.
- `scripts/` - reproducible document builders.

## Evidence policy

The current checkout is a prototype. It does not implement YOLOv8 inference, a trained defect dataset, ESG carbon forecasting, or a 4D seismic solver. Those are described as proposed extensions where requested. Implemented behaviour is cited to the source files and is reported without invented accuracy or speed claims.
